Brand Identity

MMT Plugin Generator

A new layer, plugged into the protocol stack. Describe a protocol once and generate the parser that MMT-DPI loads.

Design Concept

Packet layers, one of them pluggable

The symbol. Each bar is one header of a packet's protocol stack. The top layer has become a plug: it is the parser you describe and generate, and its prongs say that it loads into MMT-DPI at run time. The gaps in the lower bars cut them into header fields, the attributes a plugin pulls out.

The colour. Montimage amber marks the new, generated layer. The lower layers step down through two deeper ambers, so the eye goes straight to the plug. The dark base matches the terminal and network-monitoring tools this generator sits next to.

The type. Inter Display, outlined to paths so every file renders the same with or without the font installed. "MMT" is a small, widely tracked Bold label. "Plugin Generator" is SemiBold with slightly tight tracking, which keeps it compact in narrow headers.
